# Senet Pathshala

Laravel-based school website and management system for Senet Pathshala.

## Project roadmap

- Public school website
- Online admission
- Notice and gallery management
- Admin dashboard
- Student, parent and teacher portals
- Attendance, fees and results

## Stack

- Laravel
- PHP
- MySQL
- Bootstrap
- JavaScript

> The repository is being built incrementally toward a production-ready deployment.
